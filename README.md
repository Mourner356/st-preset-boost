# Preset Boost - 预设性能加速

解决 SillyTavern 预设面板（Prompt Manager）的卡顿问题：
打开预设卡、编辑预设卡、长按拖拽条目排序卡。

## 原理

不修改酒馆任何逻辑，只做三件事：

1. 给预设列表加 CSS 渲染隔离（`contain`），缩小重排范围
2. 屏幕外条目延迟渲染（`content-visibility`），条目多时效果明显
3. 拖拽的那几百毫秒里，临时关闭动画、阴影、毛玻璃

可选项：全局关闭毛玻璃模糊，提速最明显，代价是界面变扁平。

## 安装

酒馆 → 扩展 → Install extension → 粘贴本仓库地址

## 使用

安装后在「扩展」面板里找到「预设性能加速」，
展开可以逐项开关。默认已启用前三项。

如果还是卡，把「关闭毛玻璃模糊」也勾上。

## 兼容

SillyTavern 1.12.x+（含 Staging）
